# 邮件配置修复指南

## 问题诊断

根据测试结果，当前的邮件配置使用了测试数据：
- SMTP服务器: smtp.gmail.com
- 用户名: test@gmail.com

这些是虚拟的测试数据，无法正常发送邮件。

## 解决方案

### 方法1：在Web界面重新配置

1. 登录网站管理系统
2. 进入"系统设置" → "邮件配置"
3. 点击"配置邮件"按钮
4. 填入真实的SMTP配置信息
5. 点击"保存配置"
6. 点击"测试邮件"验证配置

### 方法2：常用邮箱SMTP配置

#### Gmail
- SMTP服务器: smtp.gmail.com
- 端口: 587
- 安全连接: 否
- 用户名: your-email@gmail.com
- 密码: 使用应用专用密码（不是登录密码）

> ⚠️ Gmail需要开启两步验证并生成应用专用密码

#### QQ邮箱
- SMTP服务器: smtp.qq.com
- 端口: 587
- 安全连接: 否
- 用户名: your-email@qq.com
- 密码: 使用授权码（不是登录密码）

> ⚠️ QQ邮箱需要在设置中开启SMTP服务并生成授权码

#### 163邮箱
- SMTP服务器: smtp.163.com
- 端口: 465
- 安全连接: 是
- 用户名: your-email@163.com
- 密码: 客户端授权密码

> ⚠️ 163邮箱需要在设置中开启SMTP服务

#### 126邮箱
- SMTP服务器: smtp.126.com
- 端口: 465
- 安全连接: 是
- 用户名: your-email@126.com
- 密码: 客户端授权密码

### 方法3：直接更新数据库

如果需要直接更新数据库，可以执行以下SQL：

```sql
UPDATE email_configs 
SET 
    smtp_host = 'smtp.gmail.com',
    smtp_port = 587,
    smtp_user = 'your-real-email@gmail.com',
    smtp_password = 'your-app-password',
    smtp_secure = FALSE
WHERE id = 1;
```


## 常见错误及解决方案

### 1. 连接超时 (ETIMEDOUT)
- 检查网络连接
- 确认SMTP服务器地址和端口
- 检查防火墙设置

### 2. 认证失败 (EAUTH)
- 确认用户名和密码正确
- 对于Gmail/QQ邮箱，使用应用专用密码/授权码
- 确认邮箱已开启SMTP服务

### 3. 连接被拒绝 (ECONNREFUSED)
- 检查端口是否正确
- 确认服务器支持该端口
- 检查安全连接设置

## 推荐配置

对于生产环境，推荐使用：
- **Gmail**: 稳定可靠，支持应用专用密码
- **QQ邮箱**: 国内访问速度快，配置简单
- **企业邮箱**: 如果有企业邮箱，优先使用

## 安全建议

1. 不要在代码中硬编码邮箱密码
2. 定期更换应用专用密码/授权码
3. 使用SSL/TLS加密连接
4. 限制发送频率，避免被标记为垃圾邮件

## 测试步骤

1. 保存配置后，点击"测试邮件"
2. 检查邮箱是否收到测试邮件
3. 测试登录验证码功能
4. 测试忘记密码功能
5. 测试网站告警通知功能

如果所有测试都通过，说明邮件配置已成功修复。
